# Game Prototype 開発の軌跡と技術的総括 (RETROSPECTIVE)

## 1. プロジェクトの背景と目的
`game_prototype` は、ユーザー発案の本格ボードゲーム構想 **『代理戦争・国家指導者アカデミー（仮）』** を実現するために開発されたCLIプロトタイプである。

プレイヤーは国家元首としてAI執政官（エージェント）に自然言語で「助言・指導」を与え、AIはゲームマスターが提示する厳格なルールの中で行動を選択する。
ここでの革新的な試みは、**「AIがプレイヤーの言うことを聞くか、それとも反抗・暴走するかを、サイコロ（乱数）ではなく潜在空間の物理学（ポテンシャルエネルギーと引力・反発）で決定する」** という点にある。

---

## 2. アーキテクチャと主要コンポーネント

### A. 概念物理型AI執政官 (`latent_ai.py`)
- **国家ドクトリンと性格スライダー:**
  - 好戦性（Aggressive: -1.0 〜 1.0）
  - 合理性（Rational: -1.0 〜 1.0 / 服従度）
  - 協調性（Coop: -1.0 〜 1.0）
  これらを元に、3次元の潜在空間 `[軍事(Military), 内政(Economy), 外交(Diplomacy)]` 上にAIの **性格アトラクター（深い谷）** を形成。
- **助言のドリフト力（外力）:**
  - プレイヤーの入力テキスト（例:「今は内政をして資金を貯めろ」）から意図ベクトルを抽出。
  - 合理性（Rationality）パラメータが低いAIは外力の重みが小さく、自分自身の性格アトラクターへ強く引き戻される。
- **物理計算による反抗の成立:**
  - `最終ベクトル = (助言ベクトル * 服従係数) + (性格アトラクター * (1 - 服従係数))`
  - 最も値が高い次元を行動として採択。助言と異なる行動が選ばれた場合、**「主よ、あなたの命令は我が国の教義に反します！」** というエモーショナルな思考ログを出力して独断専行（反抗）する。

### B. インタラクティブUIループ (`main.py`)
- 国家作成フェーズ ➔ 状況報告（Phase 2） ➔ 指導フェーズ（Phase 3） ➔ 物理計算＆行動実行（Phase 4）というゲームループをCLI上で再現。

## 3. 直面した技術的課題・失敗と解決策

### ① PowerShell パイプライン入力のトラップ
- **失敗内容:** 自動テスト時、PowerShell上で `python main.py < input.txt` やヒアドキュメント（`<<EOF`）を実行しようとした際、PowerShellが `<` リダイレクトをサポートしておらず構文エラーで停止した。
- **解決策:** Pythonの `unittest.mock.patch('builtins.input', ...)` を用いたプログラム内モック駆動に切り替え、OSのシェル差異に依存しない安全なテスト手法を確立した。

### ② 文字化けとエンコーディング
- **課題:** Windowsコンソール環境における日本語出力のエンコード不一致（CP932 vs UTF-8）により、AIの反抗メッセージが一部文字化けした。
- **解決策:** 出力文字列のサニタイズおよび標準I/Oバッファの最適化を行い、安定した表示を確保した。

## 4. 総括
本プロトタイプは、「LLMをゲームNPCに導入すると、返答が遅い、または言うことを聞かないだけの単なるバグに見える」というゲーム業界の長年の課題に対し、**「潜在空間の物理演算を用いることで、AIの反抗や暴走に確固たる説得力とドラマ（物理法則）を持たせる」** という鮮烈な回答を提示した。
多人数パーティーゲームや、国家運営シミュレーションにおけるAIキャラクターの新しい地平を切り拓いたプロジェクトである。
