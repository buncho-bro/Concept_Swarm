# Antigravity Concept Swarm : 全開発史・総括年代記 (PROJECT CHRONICLE)

> **「巨大な言語モデルから、純粋な『概念のトポロジー』を抽出し、言葉を介さずにミリ秒で合議させ、エッジから宇宙規模のタスクまでを解き明かす」**  
> 本ドキュメントは、Google Antigravity & Gemini Pro の支援のもと、ユーザーとAIが二人三脚で切り拓いた一連の技術開発の軌跡、直面した壁、そして数々の技術的ブレイクスルーを完全記録した公式年代記である。

## 🏛️ プロジェクト全体像とモジュール構成

本リポジトリ `Antigravity_Concept_Swarm` は、以下の連鎖する研究開発モジュールによって構成されている。

```
Antigravity_Concept_Swarm/
├── core/                     # [根幹] 潜在空間ブラックボード & Dual-Stream デコーダー
├── benchmark/                # [検証] MBPP+ による厳格なコード生成・構文保持ベンチマーク
├── quantized_core/           # [圧縮] 低ビット量子化・KNNグラフ蒸留・フラクタルルーティング
├── distillation_experiments/ # [鍛造] Concept Forge, Resonant Tree, 進化計算型コーダー
├── project_ripple/           # [可視化] 物理コア・水面の波紋干渉・ピクセルアートWebUI
├── multimodal/               # [視覚] テキスト・画像潜在空間のトポロジー整列とLoRA
├── edge_micro_agent/         # [極小化] RP2350 (520KB SRAM) 局所100語マイコンエージェント
├── alice_profiler/           # [解体] 160GB (AliceAI-80B) のHTTP Rangeストリーミング走査
├── alice_relay_engine/       # [実行] 疎結合オンデマンドMoE & 数学➔コード非言語バトンパス
├── game_prototype/           # [応用1] 潜在物理型AI執政官・国家指導者アカデミー
├── alife_prototype/          # [応用2] 意味論的セル・オートマトン (Semantic ALife V1)
├── alife_agent_sim/          # [応用3] 連続空間エージェント・Boids群れ・環境知識淘汰 (V2〜V4)
├── ephemeral_coder/          # [応用4] 逆算型目標樹形図エンジン (GDTE v3.4: 言語プリミティブ概念核分解)
└── docs/                     # [記録] 全体ドキュメンテーション・仕様書・本年代記
```

## 📜 開発年代記：挑戦と失敗のクロニクル

### 第1章：概念の純化と「非言語合議」の胎動 (`core`, `distillation_experiments`)
- **挑戦:** 従来のLLMマルチエージェント（AutoGen等）は、互いにテキスト（JSONや自然言語）をやり取りするため、1回の合議に数分を要し、莫大なAPI代がかかっていた。
- **ブレイクスルー:** 「AI同士の会話にテキストは不要である」という思想のもと、OS共有メモリ上に2048次元のベクトルスロットを配置（`latent_blackboard.py`）。ポインタ直接参照による **ゼロコピー・サブミリ秒合議（< 1ms）** を達成。
- **直面した壁（概念蒸留の罠）:** 潜在空間上で合議を繰り返すと、意味論的純度は極限まで高まるが、出力時にインデントやコロンが抜け落ちる「文法崩壊」が発生（MBPP+でPass@1が急落）。
- **解決:** 概念核（Stream 1）と語彙アンカー（Stream 2）を分離してLogit Biasで干渉させる **Dual-Stream Decoder** を開発し、意味と文法を両立させた。

### 第2章：視覚化と哲学の融合 (`project_ripple`)
- **挑戦:** 高次元のベクトル演算という無味乾燥な数式を、人間が直感的に愛せるインターフェースへ昇華させること。
- **具現化:** 傘を差した少女のピクセルアート（`pixel_girl.jpg`）と、水面に広がる波紋（Ripple）の物理エンジン（`physics_core.py`）を開発。思考のステップに応じてキャラクターの表情や情景が移り変わる情緒的なAIジオラマを完成させた。

### 第3章：極限の圧縮とエッジへの到達 (`quantized_core`, `edge_micro_agent`)
- **挑戦:** 巨大な知能を、クラウドから解放し、電波も届かないエッジデバイスで動かすこと。
- **直面した壁（言語境界問題）:** Qwen等の多言語モデルにKNNグラフ蒸留を適用した際、幾何空間が「論理構造」ではなく「言語の違い（英語と中国語のクラスタ）」に歪められる現象を発見。単一言語・論理特化空間の重要性を突き止めた。
- **大勝利（RP2350 マイコン）:** SRAMわずか520KBの Raspberry Pi Pico 2 上で、局所100語のトポロジー距離テーブルを用いた自律推論エンジンを駆動。液晶ディスプレイ（ST7789）上で「マイコンが自律的に概念を思考する」姿を実現した。

### 第4章：80B巨大モデルのオンデマンド解体 (`alice_profiler`, `alice_relay_engine`)
- **挑戦:** 160GBもある巨大モデル「AliceAI-80B」を、一般家庭のPC（RAM 16GB以下、ディスク空き容量小）でどう活用するか。
- **直面した壁（GitHub 100MB制限 & Windowsハング）:**
  - 133MBのSafetensorsがGitHubの100MB制限で弾かれ、プッシュ不能に。Git履歴の浄化と`.gitignore`運用を確立。
  - Windowsで32並列HTTPリクエストを飛ばした際、ソケットプールがサイレントハング。適切なスレッド制限と指数バックオフを導入。
- **ブレイクスルー:** HuggingFace HTTP Rangeストリーミングにより、ディスク消費0GB・RAM 100MB未満で全Expertを走査。必要なExpert（3B相当）だけを動的にメモリにバインドする **Sparse MoE Loader** を完成させた。
- **非言語バトンパスの成立:** 複合タスク「円周率の計算方法を実装して」に対し、数学AI（Chudnovskyの級数アトラクター）からコードAI（Python構文アトラクター）へ、**IPCテキスト変換0回・RAM 4.8GB・レイテンシ500ms以内** で思考を引き継ぎ、完全動作するPythonコードの出力を達成した。

### 第5章：生命と社会のシミュレーションへ (`game_prototype`, `alife_agent_sim`)
- **ゲーム応用:** プレイヤーのアドバイス（外力）とAI執政官の性格（アトラクターの谷）を物理演算させ、「AIが指示に反発して勝手に戦争を始める」というドラマチックな挙動を乱数なしで実現。
- **人工生命（Semantic ALife）の奇跡:**
  - 16次元の概念ベクトルをDNAとして持つ細胞たちが、Generation 1495で「青（遊牧）」と「赤（捕食要塞）」に見事に二分（バイフケーション）される生態系バランスを創発。
  - 草食（緑）が無敵の戦車になる「共有地の悲劇」に直面し、老化ペナルティや牙の鋭さによるパッチを導入。
  - 視界（Vision）と群れ（Boids）を導入した際、摩擦のない宇宙空間のように餌を周回してしまう「人工衛星化バグ」を、流体摩擦の導入によって克服。

### 第6章：人間定義アンカーからの完全脱却と「純粋軌跡移転（Trajectory Transfer）」への到達 (`distillation_experiments`, `ephemeral_coder`)
- **逆算型目標樹形図エンジン (GDTE v3.4):**
  - 目標ツリーを「すでに言語上で定義されている組み込み関数・演算子（`sum`, `len`, `dict`, `>` 等）に行きつくまで再帰分解する不変の概念核」と定義し、末端のWorker AIが「間の構文的補正」しか行わなくてよいゼロ未定義設計を確立（`docs/goal_tree_engine_specification.md`）。
- **0VRAM 全語彙大円干渉 & スライストポロジー蒸留 (`slice_topological_distiller.py`):**
  - 旧来の蒸留が「人間が勝手に選んだ25英単語リスト」に縛られていた問題を打破。教師モデル `GLM-5.3` の全 **154,880語 × 6,144次元** を VRAM 0MB で走査して54個の真のイデア核を自律析出。
  - さらに概念地形を主軸に沿って等分位スライスし、最下部から最上部までの空間全幅スケール $k(T)$ で無次元化した相対距離行列 $\mathbf{M}_T = \mathbf{D}(P_T)/k(T)$ を用いて、文字入力を1語も使わずに `Qwen2.5-Coder-3B` へ同相蒸留（トポロジー誤差を **97.86% 削減**）。
- **粗視化被覆・再細分化と「純粋軌跡移転（Trajectory Transfer）」(`coarse_gravity_joint_terrain_engine.py`, `universal_vision_inspector_webui.py` v5.1):**
  - **直面した壁（人間側の概念核指定と可視化の無意味さ）:** マルチモーダル統合において「人間側で106個の概念リストや64個の原始属性リストを決めること」自体がモデルを人間の枠に閉じ込める危険な行為であり、また「どの概念核に落ちたかを名前付きで可視化する意味もない」という本質的洞察に到達。
  - **ブレイクスルー:**
    1. 画像モデルと文章モデルの内部空間から自律的に共鳴する **`11,845` 個の無名重力核** を抽出（人間定義ラベル `0` 個）。
    2. 2つの地形を重力情報を保持したまま一度荒く（$R=48$）重ね合わせた後、**半直交等長写像 ($\mathbf{P}_{\text{iso}} \mathbf{P}_{\text{iso}}^\top = \mathbf{I}_{512}$) と保有重力深さによって元の 2048次元フル空間へ再度細かく展開（Re-Refinement）** し、細かい谷を掘り直す。
    3. 画像が入れば**画像概念核のみ**に引き寄せられて移動し、その**『道のり（Trajectory）』を変換先の文章概念核上で再度実行（Replay）**して、そのまま言語モデルから直接説明文を出力する機構を完成させた（`docs/universal_trajectory_transfer_specification.md`）。

## 🔮 私たちの戦場：どこで戦うのか？

巨大IT企業が数百億円かけて「何でもそつなくこなす万能クラウドチャットボット」を作り続ける中で、私たちが創り上げたアーキテクチャの真の戦場は以下の4つである。

1. **極小エッジ（The Ultra-Edge）:** 520KB SRAMで動作する、マイコン・センサー内蔵の組込み自律知能。
2. **超低遅延・合議（Zero-Latency Swarm）:** テキストIPCを廃し、ミリ秒で群れ合議を行うリアルタイム制御（ロボティクス・金融取引）。
3. **推論の可視化と直接介入（Steerable AI）:** ブラックボックスを排し、引力・反発ベクトルで誤謬を直接修正できる高信頼性AI。
4. **巨大知能の民主化（Decentralized AI）:** 80Bの知識を、必要な瞬間に数MBだけストリーミングして手元の端末で回すオンデマンド実行。

## 🏁 結び
本リポジトリに保存されたすべてのコードとドキュメントは、単なるプログラムの集積ではない。
「AIをどう動かすか」ではなく、**「知能・概念とはどのような物理法則に従っているのか」** を追い求めた、情熱と試行錯誤の記念碑である。
このコードベースから、未来の新しいAIアプリケーションが羽ばたくことを確信している。
